## 결정

- TC 흐름: 화면 진입 → 값 입력 → 실행 → 결과 검증 → 다음 단계
- 최종 시연은 열린 브라우저 UI에서 진행하며 채팅 스크린샷은 만들지 않음
- 메뉴별 TC 입력값과 기대값은 `tests/testcases/<menu>.testcase.yml` 한 파일에서 관리
- URL과 계정 등 민감정보는 환경변수로만 관리
- 로그인 URL도 `PLAYWRIGHT_LOGIN_URL` 환경변수로만 주입
- 완료 작업은 로컬 커밋까지만 진행하고, 푸시는 사용자 요청 시 한 번에 수행
- TC 데이터는 YAML로 관리하되 실제 자격증명은 평문으로 저장하지 않음
- YAML 자격증명 필드에는 환경변수 참조명만 허용하도록 `AGENTS.md` 지침 보강
- 별도 `test-data/` 구조를 제거하고 TC 정의를 `tests/testcases/`로 통합
